# Heros Player v1.1.0 — Pure Remote

> Panel-only. No local files. Full detection + full control of YouTube Music
> and every media tab. Free forever, unlimited everything (MIT).

## Highlights

- **True remote** — title, artist, album, cover, position/duration read live
  from MediaSession + the YouTube Music player bar
- **Real-button control** — Next/Prev/Like click the site's own buttons, so
  queues, radios and autoplay never break
- **Live seek + remote volume** — drag-to-jump, ±10s nudge, 0.25x–2x speed,
  shuffle / repeat / thumbs with live pressed-state
- **Radar** — sounding tabs + music-site standby + deep scan for hidden players
- **Yours** — starred songs, notes, 100-deep history (JSON/TXT), top played,
  listening time + daily goal, copy + find-anywhere
- **Calm** — sleep, fade-out, focus-25, stop-after-song, single-source,
  song-change notifications, per-site volume memory
- **Surgery** — pause/mute all, mute-by-site, close others/duplicates,
  pin/unpin, reload, pop-out

## Install (30 seconds)

1. Download `heros-player-v1.1.0.zip` below and unzip
2. Open `chrome://extensions` (or `edge://`, `brave://`), enable Developer mode
3. **Load unpacked** → select `heros-player-extension/`
4. Click the toolbar icon → the **side panel** opens
5. Open YouTube Music, press play — full remote in ~1s
