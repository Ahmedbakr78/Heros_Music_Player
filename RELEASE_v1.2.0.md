# Heros Player v1.2.0 — Cover fix + more power

> The broken cover tile is fixed, the in-app feature list is back and bigger,
> and the remote learned new tricks. Free forever, unlimited everything (MIT).

## Fixed

- **Cover art renders again** — the probe returns the player image on its own
  channel, unloadable `blob:` artwork is rejected, the letter cover sits
  behind the photo, and no stray "cover" text can show through.

## Added

- **More pane** — the full feature universe, grouped (Detect / Control /
  Songs / Calm / Surgery), inside the app.
- **Up Next queue** — the site queue (YouTube Music) appears in Control;
  tap any row to jump straight there.
- **Notification buttons** — song alerts carry Play/Pause + Next actions;
  clicking the alert jumps to the tab.
- **Tab filter** — instant search across the radar and standby lists.
- **Compact mode** — shrunken hero for tiny panels (Tools toggle, persisted).

## Install / update (30 seconds)

Reload the extension on `chrome://extensions` (Developer mode → reload icon
on the Heros Player card), or load the attached
`heros-player-v1.2.0.zip` unpacked. Full guide:
[`docs/INSTALLATION.md`](https://github.com/Ahmedbakr78/Heros_Music_Player/blob/main/docs/INSTALLATION.md).
