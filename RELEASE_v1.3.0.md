# Heros Player v1.3.0 — More power everywhere

> Queue copy, seek-to prompt, PiP, mute-others, reload-all, reopen-closed,
> streaks, links export, history clear, play counts. Free forever, unlimited
> everything (MIT).

## Added

- **Queue copy** — Up Next list to the clipboard in one tap.
- **Seek-to prompt** — jump to any `m:ss` via `Go to…`.
- **Picture-in-Picture** — pop video tabs into an overlay.
- **Mute others** — silence everything except the controlled tab.
- **Reload all** — refresh every music tab when players glitch.
- **Reopen closed tab** — undo a close (new `sessions` permission).
- **Play counts + all-time + streak** — per-song `Nx`, total time, day streak
  in the Today row.
- **Starred-links export** — your stars as playable search links.
- **History clear** — one-tap wipe with confirm (stars stay).
- **`G` shortcut** — jump to the controlled tab.

## Install / update (30 seconds)

Reload the extension on `chrome://extensions` (Developer mode → reload icon
on the Heros Player card), or load the attached
`heros-player-v1.3.0.zip` unpacked. Full guide:
[`docs/INSTALLATION.md`](https://github.com/Ahmedbakr78/Heros_Music_Player/blob/main/docs/INSTALLATION.md).
