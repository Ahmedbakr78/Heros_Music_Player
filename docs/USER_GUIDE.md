# User Guide — the full remote, end to end

## 1. Control pane (your cockpit)

- **Target card** — what you're driving right now, with Pin-tab / Reload /
  Mute-site surgery buttons and a Go-to-tab shortcut.
- **Follow switch** — on: the panel chases whatever is sounding. Off + Control
  button on a radar row: that tab is pinned forever.
- **Quick launch** — one tap opens YouTube Music, YouTube, Spotify, SoundCloud.
- **Nudge & presets** — ±10s jumps, 0.5x–2x speed, 25–100% volume, Go-to `m:ss` prompt, PiP for video tabs.
- **Up next** — the site queue with tap-to-jump + Copy button.
- **Poll speed** — Turbo 0.5s (live progress), Normal 1s, Calm 2s (quieter CPU).

## 2. The player bar (the remote itself)

Top row is position: elapsed, draggable seek, duration. Middle row is
transport: shuffle, previous, big play/pause, next, repeat (cycles the site's
modes). Bottom row is loudness + love: tab mute, volume slider, like,
dislike — each showing live pressed-state from the site.

Click the **cover art** to jump to the tab. Full keyboard map:

| Keys | Action |
|---|---|
| Space | Play / Pause |
| ArrowRight / Left | Seek ±10s |
| ArrowUp / Down | Remote volume |
| N / P | Next / Previous |
| M | Mute tab |
| L | Like (site) |
| F | Star song (kept in Songs) |
| C | Copy `Title — Artist` |
| G | Go to the controlled tab |
| 1–5 | Control / Tabs / Songs / Tools / More |

## 3. Tabs pane (the radar)

- **Sounding now** — every audible tab with live playing/paused state.
  Per-row: play/pause, take control, mute, go-to.
- **Standing by** — open music sites that are quiet (plus deep-scan finds).
- **Pause all / Mute all / Unmute** — one-tap browser silence.
- **Deep scan** — probes all tabs for hidden players, with a progress bar.
- **Close others / Close dups** — keep it tidy in one tap.
- **Reload all / Mute others / Reopen** — refresh glitchy players, silence
  everything but controlled, undo a tab close.
- **Filter box** — instant search across sounding + standby.

## 4. Songs pane (yours, forever)

- **Today bar** — listening minutes vs your daily goal (Tools → Daily goal).
- **Top played** — auto top-5 from history, each with a Find button.
- **Starred** — `F` on any song; find it again or unstar per row.
- **History** — last 100 detected songs with time + site and per-song play
  counts; TXT/JSON export, one-tap clear (stars stay).
- **Filter box** — instant search across starred + history.

## 5. Tools pane (calm + power)

- **Stats** — commands sent, sounding now, music tabs, songs seen.
- **Sleep timer** — pause (or duck-fade) after 5–120 min.
- **Fade-out timer** — volume glides to zero over 5–30 min, then pauses.
- **Focus 25m** — silence now, music auto-resumes after the break.
- **Stop after song** — one-shot pause on the next track change.
- **Single source** — newcomers auto-pause so only one soundtrack plays.
- **Song alerts** — OS notification per song. **Volume memory** — per-site
  volume auto-restore. **Daily goal** — 15–240 min slider.
- **Backup** — export/import prefs (stars, history, notes, stats), reset.

## 6. Workflows that sing

- **Night listening**: Fade-out 15 min → drift off, music lands itself.
- **Work blocks**: Focus 25m → silence, auto-resume on break.
- **Party guard**: Single source on → no overlapping tabs, ever.
- **Discovery**: Star with `F` all week → Songs → Top played → export TXT.
- **Stuck player**: Target card → Reload, no tab-hunting.
