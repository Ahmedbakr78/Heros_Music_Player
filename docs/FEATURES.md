# Heros Player — FEATURES.md (printable checklist)

Pure remote. No local files. Full YouTube Music (& co.) detection + control.

## Full detection
- [x] Every sounding tab, live (event-driven + auto-refresh)
- [x] Music sites on standby: YouTube Music, YouTube, Spotify, SoundCloud, Apple Music, Deezer, Tidal, Bandcamp, Pandora, Audiomack, Mixcloud
- [x] Per-tab state: playing / paused / sounding / muted / standing by
- [x] Header chip + toolbar badge sounding count

## Full control
- [x] Play / Pause remote (real site button, media fallback)
- [x] Next / Previous (real site buttons — queues keep working)
- [x] Live seek bar with drag-to-jump
- [x] Remote volume slider + tab mute
- [x] Shuffle, Repeat off/all/one, Like, Dislike — live states
- [x] Playback speed 0.25x–2x on the site player
- [x] Pin a tab / Follow what is sounding / Go to tab

## Power
- [x] Pause ALL / Mute ALL / Unmute ALL + Mute-by-site
- [x] Sleep timer with pause or duck-fade
- [x] Fade-out timer (5–30 min glide to silence)
- [x] Focus 25m (pause + auto-resume)
- [x] Stop after this song (auto-pause on track change)
- [x] Single-source mode (newcomer pauses the rest)
- [x] Deep scan (uncovers hidden media tabs)
- [x] Close others + Close duplicates
- [x] Pin / unpin player tab, Reload stuck player
- [x] Song-change OS notifications
- [x] Site volume memory (per-site volume auto-restore)
- [x] Quick launch: YouTube Music, YouTube, Spotify, SoundCloud
- [x] Command stats + songs-seen counter
- [x] Prefs export / import / reset

## Songs (yours, forever)
- [x] Star any song (F shortcut) + one-tap Find from lists
- [x] Full 100-song history with time + site, JSON + TXT export
- [x] Song filter search + Top-played ranking
- [x] Listening time (total + today) with daily goal bar
- [x] Copy "Title — Artist" to clipboard
- [x] Nudge ±10s + speed presets 0.5x–2x + volume presets 25–100%

## Design / Privacy / Speed
- [x] Heros PDF design copy (cards, pills, dark+light, accents)
- [x] Silent boot, panel-only, Turbo/Normal/Calm polling
- [x] Full keyboard map (Space, arrows, N P M L, 1–4)
- [x] Zero frameworks, zero tracking, tab data never leaves device
